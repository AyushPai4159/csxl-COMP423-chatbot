# Computer Science Experience Labs

The Experience Labs' (XL) mission is to accelerate technical experience and build community among undergraduate CS majors at The University of North Carolina at Chapel Hill. The XL's web app, found in production at `csxl.unc.edu`, is backed by the CSXL repository located at this link: https://github.com/unc-csxl/csxl.unc.edu. The repository located here is a fork of the CSXL repository.

## Deployment Link
* [CSXL Chatbot](https://csxl-team-e3-comp423-25s.apps.unc.edu/welcome) - Unfortunately this doesn't work because our deployment was shut down after Spring 2025. Refer to the docs/get_started.md referenced above. 
* To interact with the chatbot, press the robot icon on the bottom left corner. It should open a chat interface.
* In the text space, type any information you want to ask the chatbot, as long it is related to UNC CS or the CSXL. Then, click the send button.
* Sample Question: What is the CSXL?
* It should be mentioned that the chatbot is programmed to give a fixed response since our API Key expired. Just use your imagination!
* You can also look at previous chat threads by clicking the session button on the bottom right of the Chat UI.
